Guia de estudio SAA-C03

El simulacro de PrepAWS tiene 65 preguntas y dura 130 minutos. La meta de practica es acertar 47. AWS usa una escala propia con un puntaje minimo de 720 sobre 1000.

Dominios del examen

  • Seguridad (30%, 19 preguntas en el simulacro)Elige roles y politicas de IAM con los permisos minimos. Revisa el acceso a S3 y las politicas de claves de KMS.
  • Resiliencia (26%, 17 preguntas)Compara RDS Multi-AZ con las replicas de lectura. Decide cuando usar conmutacion por error en Route 53 o desacoplar servicios con SQS.
  • Rendimiento (24%, 16 preguntas)Compara tipos de instancia EC2 y volumenes EBS segun la carga. Revisa como los indices de DynamoDB y la cache de CloudFront afectan la latencia.
  • Costos (20%, 13 preguntas)Elige clases de almacenamiento y reglas de ciclo de vida de S3 segun la frecuencia de acceso. Compara opciones de compra de EC2 segun la demanda.

Practica por tema

Elige un dominio para practicar un bloque de 15 preguntas. Usa el filtro de tema para concentrarte en un servicio. Excelencia operativa y General tambien estan disponibles para practicar por separado.

  • RedesCompara Direct Connect y las interfaces virtuales para redes hibridas. Distingue entre VPC endpoints de interfaz y de gateway.
  • AplicacionesRevisa los tipos de invocacion de Lambda, las suscripciones de SNS y las colas FIFO de SQS. Compara las opciones de ECS y EKS con Fargate.
  • DatosRepasa las copias de seguridad de RDS y los endpoints de Aurora. Revisa el particionado en Athena y las claves de ordenamiento de Redshift.
  • Excelencia operativaUsa CloudWatch para metricas y alarmas, CloudTrail para auditar llamadas a la API y AWS Config para revisar cambios de configuracion.
